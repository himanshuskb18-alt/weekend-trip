# ✦ Roamly — Travel Discovery Website

Roamly is a modern, responsive travel discovery website designed to help users find beautiful weekend destinations based on their mood, available time, budget, and travel distance.

The website provides a simple and elegant travel experience where users can explore destinations, view details, check routes, calculate distance, and save their favorite trips.

---

## 🌍 Features

- ✦ Modern and responsive travel UI
- 🏔️ Explore curated travel destinations
- 🎯 Destination recommendations
- 💰 Budget-based destination information
- 🕐 Estimated travel time
- 📍 Distance from current location
- 🗺️ Interactive map
- 🚗 Route calculation
- 📌 Current location detection
- ❤️ Save favorite destinations
- 🎲 Surprise Me destination feature
- 🔎 Destination search
- 📱 Mobile responsive design
- 🌤️ Destination details and highlights
- 🗓️ Suggested itinerary
- 📅 Best time to visit

---

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

### Maps & Location

- Leaflet.js
- OpenStreetMap
- Nominatim Geocoding API
- OSRM Routing API
- Browser Geolocation API
